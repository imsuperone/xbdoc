聊天指令与快速入门

本页提供群聊指令速查、生效模式说明与检索原理介绍。

1. 群聊指令（仅群管理员可修改配置）
查看
/xbdoc status查询本群的绑定、模式、屏蔽与提示词状态
/xbdoc list查询知识库中的全部文档及其 ID
/xbdoc workspace查询工作区挂载清单与容量占用
/xbdoc search <词>在本群绑定的文档中进行检索
/xbdoc read <ID> [n]预览指定文档的切片内容
绑定
/xbdoc bind <ID...>追加绑定，将自动合并（私聊会话中可直接使用）
/xbdoc unbind [ID...]解除绑定；参数留空则清空全部绑定，提示词将一并清除
私聊绑定与机器人进行私聊后，系统将自动记录该会话，可在 WebUI 中按昵称或 UID 搜索绑定，亦可手动填写 private:UID
模式（需先绑定文档）
/xbdoc mode s|w|r切换为强制遵守、工作区或仅参考模式
/xbdoc shield on|off开启人格屏蔽或恢复原人格
/xbdoc force on|off设置专属提示词是否作为唯一系统提示词生效
提示词
/xbdoc prompt查看本群的提示词配置详情
/xbdoc prompt_set <内容>设置本群的专属提示词
/xbdoc prompt_clear清除本群的专属提示词
历史
/xbdoc no [off]清除此前消息记录，或恢复消息读取
2. 四大生效模式说明

• 强制遵守文档（系统提示词模式）：将文档核心内容作为最高优先级系统提示词载入大模型，专属提示词将作为额外提示词追加，AI 将严格遵守并执行文档中的角色设定与规则。
• 模拟工作区模式（项目沙箱）：将已绑定的文件作为工作区沙箱挂载，大模型将严格基于工作区内挂载的文件进行分析、开发与解答，不附加其余提示词。
• 仅作参考资料模式（知识库问答）：文档将作为外部知识库，提问涉及相关内容时，系统将自动检索切片并作为参考资料引用回答。
• 无（不注入）：已绑定的文档将被保留，但不会注入上下文，仅专属提示词与人格屏蔽等配置生效，适用于临时停用文档引用的情形（新建绑定默认为此模式）。

3. 零向量模型检索原理与用量说明

本插件无需配置向量模型（Embedding），通过中英文分词与词频动态加权机制实现快速精确定位，自动提取相关度最高的若干切片注入大模型上下文，从而显著降低用量并保持较快的响应速度。
