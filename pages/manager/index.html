1. 群聊指令（仅群管理员可改配置）
📖 查看
/xbdoc status本群绑定、模式、屏蔽、提示词状态
/xbdoc list知识库全部文档与 ID
/xbdoc workspace工作区挂载清单与容量
/xbdoc search <词>检索本群绑定文档
/xbdoc read <ID> [n]预览文档指定切片
🔗 绑定
/xbdoc bind <ID...>追加绑定，自动合并（私聊里直接对自己用即可）
/xbdoc unbind [ID...]解绑；留空全清，提示词一并清除
私聊绑定和机器人私聊任意一句即被记录，WebUI 搜昵称/UID 绑定，或手填 private:UID
🎛️ 模式（需先绑定文档）
/xbdoc mode s|w|r强制遵守 / 工作区 / 仅参考
/xbdoc shield on|off清空 / 保留原人格
/xbdoc force on|off专属提示词唯一生效
🏷️ 提示词
/xbdoc prompt查看本群配置详情
/xbdoc prompt_set <内容>设置专属提示词
/xbdoc prompt_clear清除专属提示词
🧹 历史
/xbdoc no [off]忘掉此前消息 / 恢复读取
2. 四大生效模式说明

• ⚡ 强制遵守文档（系统提示词模式）：将文档核心内容直接作为最高优先级系统提示词载入大模型，专属提示词作为额外提示词追加，强制 AI 无条件遵守并执行文档里的角色设定与规则。
• 💻 模拟工作区模式（项目沙箱）：将绑定的文件作为工作区沙箱挂载，大模型严格基于工作区内挂载的文件进行专业分析、开发与解答，0其余说教提示词。
• 📖 仅作参考资料模式（知识库问答）：文档作为外部知识库，提问相关内容时自动检索切片作为参考资料引用回答。
• 🚫 无（不注入）：绑定的文档保留但完全不注入上下文，仅专属提示词/人格屏蔽等配置生效，适合临时停用文档引用（新建绑定默认为此模式）。

3. 零 Embedding 检索原理与 Token 节省

本插件无需额外配置向量模型（Embedding），通过中英文分词与 TF 动态加权机制进行快速精准定位，自动提取 Top-K 切片注入大模型上下文，极大降低 Token 消耗并保持极速响应。
